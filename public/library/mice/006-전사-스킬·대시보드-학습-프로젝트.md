# 전사 스킬·대시보드 학습 프로젝트

> **사용자 입력**: 본부장, 첫 번째 과제를 제시하겠어.

Claude에 있는 나의 모든 스킬을 팀장들이 모두 철저하게, 완벽하게 학습해 줘. 그리고 거기에 내가 만들어 놓은 굉장히 많은 대시보드들이 있어. 대시보드들 내용까지도 모두 학습해 줘.

학습 계획을 수립하고, 학습을 진행하고, 학습 결과에 대해서 테스트해 줘. 그리고 그 결과를 가지고 어떤 활용이 가능한지에 대한 아이디어를 각 팀장별로 2가지씩 제시하라고 해 줘.

마감은 1시간 줄 테니까, 오늘 저녁 10시 22분까지 종료해 줘. 가능한지 판단해서 답변해 주시기 바랍니다.
> **본부장 배정 사유**: 전체 스킬 인벤토리 조사 및 대시보드 자료 수집은 기획팀장이 주관하고, 4팀장 학습 분배·테스트·활용 아이디어 취합은 본부장이 지휘합니다. 산출물: 학습 계획서 + 팀장별 테스트 결과 + 활용 아이디어 8건(팀장당 2건).

## 1. 현황 파악 — 무엇이 문제인가

### 1-1. 정보 접근 제약 [확인 필요]

| 항목 | 현재 상태 | 문제 |
|------|-----------|------|
| Claude 내 "스킬 목록" | **공개 API 없음** | Claude는 대화 세션 외부에 스킬 저장소를 별도 제공하지 않음 |
| "본부장의 대시보드" | **위치 미지정** | Notion·Figma·Google Data Studio 등 어느 플랫폼인지 불명 |
| 팀장 4명 | **연결 채널 미지정** | 동시 학습 진행 방식(채팅·문서·영상) 미확정 |

→ **기획팀장 단독으로는 원천 데이터에 접근할 수 없음**. 본부장이 직접 스킬 목록과 대시보드 링크를 제공해야 작업 착수 가능.

### 1-2. 1시간 타임박스 분석

```
[지시된 작업 분량 추정]
 스킬 인벤토리 수집·정리       → 최소 30분
 대시보드 전수 파악·요약        → 최소 45분 (수량 미확인)
 팀장 4명 학습 분배·진행       → 최소 60분
 팀장별 테스트 설계·채점        → 최소 40분
 활용 아이디어 8건 작성         → 최소 30분
 ───────────────────────────────────
 합계 [추정]                   → 최소 205분 (약 3시간 25분)
```

**현실적으로 22:22까지 전 과정 완료는 불가능**합니다. 단, 아래 조건이 충족되면 **핵심 산출물 3종**을 1시간 내 완성할 수 있습니다.

## 2. 재설계안 — 1시간 내 실현 가능한 범위

### Phase 0 (지금 즉시, 5분)
본부장이 제공해야 할 인풋:
- [ ] Claude 스킬 목록 (텍스트·링크·캡처 중 하나)
- [ ] 대시보드 URL 또는 플랫폼명 + 접근 권한
- [ ] 팀장 4명 명단 및 역할 (사업·감사·운영·기획)

### Phase 1 (22:00~22:10, 10분) — 기획팀장 주관
- 스킬 인벤토리 → 팀장별 도메인 매핑 표 작성
- 대시보드 구조 분류 (사업/운영/재무/MICE 등)

### Phase 2 (22:10~22:25, 15분) — 본부장 지휘
- 팀장 4명에게 학습 패키지 분배
- 각자 읽기·요약 진행

### Phase 3 (22:25~22:40, 15분) — 기획팀장 설계·본부장 집행
- 팀장별 5문항 퀴즈 테스트
- 결과 취합

### Phase 4 (22:40~22:55, 15분) — 전체 취합
- 활용 아이디어 팀장당 2건 제출
- 최종 보고서 초안 완성

### Phase 5 (22:55~22:22, 예비)
- 감사팀장 팩트체크 + 최종본 발송

### 의심 항목 / 빨간 깃발

- ⚠️ **[시간 표기 오류]** Phase 5 블록에 `22:55~22:22`로 기재되어 있음. 22:55 이후가 22:22로 되돌아가는 것은 시간 역행으로 불가능. 문맥상 `22:55~23:00(또는 23:22)` 또는 예비 블록 제거가 맞는 것으로 추정되나, 의도한 마감 시각이 22:22인지 23:22인지 본부장 원문과 대조 필요.
  - **권고**: 본부장 원문의 "저녁 10시 22분"이 22:22임을 확인하고, Phase 5 시간대를 삭제하거나 `22:55~22:22(초과·불가)` 취지임을 명시적으로 주석 처리할 것.

- ⚠️ **[내부 일정 모순]** Phase 1~5 합산 소요 시간: 10 + 15 + 15 + 15 + α분. Phase 0 시작점이 "지금 즉시"인데, Phase 1 시작이 `22:00`으로 고정 기재되어 있음. 작성 시각이 22:00 이전이면 문제없으나, 22:00 이후라면 Phase 1 시작 시각 자체가 이미 경과. 작성일시 `2025-01-23` 기재만 있고 **시각(HH:MM)이 누락**되어 일정 정합성 독립 검증 불가.
  - **권고**: 작성 헤더에 `작성일시: 2025-01-23 21:XX` 형태로 시각 추가; Phase 1 시작 시각을 고정값이 아닌 `인풋 수령 후 T+0분` 형태로 변경 권장.

- ⚠️ **[추정 미표기 1건]** 섹션 5 표 제목 `활용 아이디어 사전 풀`의 **컬럼 헤더(아이디어 A·B)**와 각 셀 내용에는 `[추정]` 표기가 있으나, **표 바로 위 도입문** `"팀장별 2건, 목록 확정 후 구체화"` 문장 자체에는 미확정 표시가 없어 확정 내용으로 오독될 소지.
  - **권고**: 도입문 앞에 `[초안/추정]` 레이블 추가.

### 검증 메모
- **외부 출처 검증**: 본 산출물은 외부 URL·법조문·공시 수치를 포함하지 않으므로 WebFetch·opendart·KiprisPlusMCP 조회 해당 없음
- **수치 독립 출처 확인**: 205분 추정치는 항목별 분해로 내부 검산 완료(30+45+60+40+30=205); 단일 출처이나 외부 데이터 아닌 내부 업무 추정치이므로 3소스 룰 적용 예외 처리
- **현행 법령·규정**: 해당 없음
- **추정·확인 필요 마킹 누락**: 섹션 5 도입문 1건 누락 확인 → 빨간 깃발 처리 완료
- **전반적 판단**: 핵심 오류는 시간 표기 역행 1건이며 내용 신뢰도에 직접 영향을 주지는 않으나, 외부·상위 보고용 문서이므로 수정 후 재제출 권장
