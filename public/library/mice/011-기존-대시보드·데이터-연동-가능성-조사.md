# 기존 대시보드·데이터 연동 가능성 조사

> **사용자 입력**: 내가 만든 그 대시보드나 여러 가지 데이터 자료들하고는 전혀 호환이 안 되나? 그 데이터들을 기반으로 해서 작업을 하기를 원하는데, 그러려면 어떤 조치가 필요한지 확인해서 보고해 줘.
> **본부장 배정 사유**: 사용자 보유 대시보드와 데이터 자료의 위치·형식·접근 경로를 조사하고 현재 4팀장 시스템과의 연동 방안을 정리합니다. 자료 조사 성격이므로 기획팀장이 적합합니다.

## 1. 현황 파악 — 무엇이 문제인가

현재 본부장이 보유하신 대시보드 및 데이터 자료와 4팀장(기획·사업·감사·재무) AI 시스템 간의 **직접 연동 경로가 설정되어 있지 않은 상태**입니다.

이는 기술적 불호환 문제라기보다, **데이터 위치·형식·접근 권한이 아직 공유되지 않은 정보 단절 문제**에 가깝습니다.

핵심 공백은 아래 세 가지입니다:

| 공백 항목 | 현재 상태 | 필요 조치 |
|---|---|---|
| 데이터 위치 | 미확인 | 저장 경로·플랫폼 공유 |
| 데이터 형식 | 미확인 | 파일 타입 확인 |
| 접근 권한 | 미확인 | 공유 링크 또는 업로드 |

---

## 2. 가능한 데이터 형태별 연동 방안

### ① 엑셀 / CSV / 스프레드시트

- **Google Sheets**: 공유 링크(뷰어 또는 편집자) 제공 시 → 팀장 시스템에서 URL 기반으로 직접 참조 가능
- **Excel 파일(.xlsx)**: 대화창에 직접 첨부 시 → 내용 파싱 후 즉시 활용 가능
- **CSV**: 동일. 첨부 또는 텍스트 붙여넣기로 처리 가능

> **권고**: 가장 빠른 방법은 파일 직접 첨부 또는 Google Sheets 공유 링크 제공

---

### ② 대시보드 툴 (Tableau / Power BI / Looker Studio 등)

| 도구 | 연동 가능성 | 방법 |
|---|---|---|
| **Looker Studio** | 높음 | 보고서 URL 공유 + 스크린샷/데이터 내보내기 |
| **Power BI** | 중간 | 데이터 원본(Excel·DB) 직접 공유가 더 효율적 |
| **Tableau** | 중간 | `.twbx` 파일 또는 원본 데이터 공유 권장 |
| **Notion 데이터베이스** | 높음 | 공개 링크 공유 시 내용 참조 가능 |
| **Airtable** | 높음 | CSV 내보내기 또는 공유 링크 |

> **주의**: 대시보드 시각화 자체보다 **원본 데이터(raw data)** 를 공유하는 것이 분석 품질을 높입니다.

---

### ③ 문서형 자료 (PDF / PPT / Word)

- PDF·PPT·Word 파일 → 대화창 첨부 시 내용 인식·분석 가능
- 단, **편집 가능한 형태**(원본 파일)가 PDF보다 정보 손실이 적음
- 이미지로만 구성된 PDF는 [확인 필요] — OCR 처리 필요 여부 사전 확인 요망

---

### ④ 외부 DB / API 연동

- 사내 DB(MySQL, PostgreSQL 등) 또는 외부 API가 있는 경우 → **MCP 도구 또는 API 키 연결** 방식으로 실시간 연동 가능 [확인 필요 — 현재 인프라 구성 미파악]
- 나라장터, 공공데이터포털 등 공개 API는 현재 도구셋으로 직접 수집 가능

## 3. 연동 실행을 위한 체크리스트

본부장이 아래 항목에 답해주시면 **즉시 연동 설계 착수** 가능합니다.

- [ ] 대시보드/데이터가 저장된 **플랫폼 또는 파일 형식**은?
  - (예: Google Sheets, Excel, Notion, Tableau, Airtable, 기타)
- [ ] 해당 자료의 **주요 내용 카테고리**는?
  - (예: 행정사 매출 현황, 산단 분양 데이터, MICE 수주 현황, 호텔 시세 등)
- [ ] **업데이트 주기**는 어떻게 되나요?
  - (실시간 / 주간 / 월간 / 비정기)
- [ ] **접근 방식** 선호는?
  - (파일 첨부 방식 / 공유 링크 제공 / API 연결)

## 4. 권고 연동 아키텍처 (초안)

```
[본부장 보유 데이터]
        ↓ (공유 링크 or 파일 첨부)
[기획팀장] ─── 수집·정제·분석 ──→ [사업팀장] 구축 BOM 인계
        ↓
[감사팀장] 팩트체크 (필요 시)
        ↓
[재무팀장] 수익성·비용 분석 반영
```

- 데이터는 **기획팀장이 1차 수령·정제** 후 각 팀장에게 목적별로 인계하는 구조가 효율적
- 반복 작업이라면 **정기 보고 템플릿** 설계 제안 가능
