- ⚠️ **[추정] 비용 비중 수치의 출처 불명확** — 섹션 4에서 인건비 `~30–35%`, 식자재 `~10–15%`, 에너지비 `~5–8%`, OTA 수수료 `~8–12%`를 "국내 중소형 호텔 업계 평균 기준"이라고 명시했으나, 구체적인 출처(한국호텔업협회 통계, 관광지식정보시스템 등)가 인용되지 않음. 외부 발송 시 클라이언트가 수치의 신뢰성을 문의할 경우 근거 제시 불가 → **출처 URL 또는 발간 보고서명·연도 추가 기재 권고**

- ⚠️ **어린이날 날짜 표기 오류 가능성** — 섹션 3-2에서 "어린이날(5/5), 어버이날(5/8)"로 기재되어 있으나, 2025년 5월 5일(월)은 어린이날 대체공휴일 없이 당일 공휴일이며 5월 6일(화)은 별도의 임시공휴일·대체공휴일이 아님. 섹션 5의 "5월 연휴(5/5–6)"도 동일 맥락에서 5/6이 공식 공휴일인지 확인 필요. **5/6은 일반 평일(화요일)**로, "연휴"로 표현하는 것은 사실과 다를 수 있음 → **2025년 5월 달력 기준 공휴일·임시공휴일 재확인 및 수정 권고** (**외부 검증 필요** — 기획재정부 임시공휴일 고시 확인 요망)

- ⚠️ **OTA 수수료율 범위의 현행성 미검증** — `~8–12%`는 일부 OTA(야놀자, 여기어때 등 국내 플랫폼) 기준과 상이할 수 있으며, 글로벌 OTA(Booking.com, Expedia 등)의 경우 15–20% 수준도 일반적임. "중소형 호텔"이라는 전제 하에 국내 OTA 위주라면 적정 범위일 수 있으나, 조아호텔이 실제로 사용하는 OTA 채널이 확인되지 않은 상태에서 해당 수치를 기재하면 오해를 유발할 수 있음 → **조아호텔 실제 OTA 계약 채널 및 수수료율 확인 후 수치 조정 권고**
